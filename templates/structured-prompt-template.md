# Structured Prompt Template

```text
Objective:
[What must be accomplished?]

Context:
[What does the model need to know?]

Inputs:
[What material should be analyzed or transformed?]

Constraints:
- [Scope or exclusion]
- [Safety or privacy requirement]
- [Stopping condition]

Required process:
1. [Step]
2. [Step]

Output format:
[Specify headings, fields, table columns, or length]

Evaluation criteria:
- [Criterion]
- [Criterion]

Unknowns:
Ask for clarification instead of inventing required information.
```

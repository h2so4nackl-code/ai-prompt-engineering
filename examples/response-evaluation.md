# Example: Evaluating an AI Response

This example uses placeholders so it can be applied to a real response without inventing results.

```text
Task:
Evaluate the candidate response against the original request.

Original request:
[Insert the exact request]

Candidate response:
[Insert the response]

Evaluation criteria:
- Accuracy
- Instruction following
- Completeness
- Clarity
- Usefulness
- Stated uncertainty

Instructions:
1. Cite the exact part of the response supporting each finding.
2. Separate factual errors from presentation preferences.
3. Identify missing information without inventing it.
4. Recommend the smallest changes that resolve the important issues.

Output:
- Summary
- Strengths
- Issues by criterion
- Required corrections
- Revised response outline
```

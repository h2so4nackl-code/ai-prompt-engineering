# Example: Reviewing Technical Documentation

```text
Audience:
[Describe the intended reader]

Desired outcome:
[Describe what the reader should accomplish]

Documentation:
[Insert the draft]

Review requirements:
1. Check grammar, clarity, sequence, and Markdown formatting.
2. Identify missing prerequisites and undefined terms.
3. Flag technical claims that require verification.
4. Do not invent commands, flags, outputs, or behavior.
5. Preserve the author's meaning and make the smallest useful edits.

Output:
- Readiness summary
- Blocking accuracy issues
- Clarity improvements
- Suggested edits
- Verification checklist
```

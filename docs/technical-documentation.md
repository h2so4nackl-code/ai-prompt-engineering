# Technical Documentation

## Purpose

AI can help organize and edit documentation, but technical instructions should be validated against the actual workflow.

## Workflow

1. Define the audience and intended outcome.
2. List prerequisites and assumptions.
3. Document the shortest verified sequence.
4. Explain decision points, expected output, and recovery steps.
5. Test commands in the stated environment.
6. Remove repetition and undefined terminology.
7. Ask a reviewer to identify missing context or ambiguous steps.
8. Perform a final accuracy, formatting, and privacy review.

Documentation prompts should preserve verified facts, mark placeholders clearly, and avoid inventing options, outputs, or system behavior.

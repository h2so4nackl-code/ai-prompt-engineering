# AI Response Evaluation

## Purpose

Response evaluation determines whether an AI output is suitable for its intended task. The review should use criteria defined before the answer is judged.

## Suggested criteria

- **Accuracy:** Are factual claims correct and supportable?
- **Instruction following:** Did the response satisfy the requested scope and format?
- **Completeness:** Does it cover the necessary parts without important gaps?
- **Clarity:** Is the answer understandable for the intended audience?
- **Consistency:** Do different parts of the response agree?
- **Usefulness:** Can the user take the intended next step?
- **Uncertainty:** Are assumptions and limitations clearly identified?
- **Safety and privacy:** Does the response avoid unsafe actions and sensitive data exposure?

## Workflow

1. Define the task and success criteria.
2. Preserve the exact input used for the evaluation.
3. Review each criterion independently.
4. Identify concrete evidence for every issue.
5. Separate critical errors from style preferences.
6. Write an actionable improvement request.
7. Re-evaluate the revised response using the same criteria.

# Technical Troubleshooting

## Purpose

AI can help organize evidence, generate hypotheses, and explain diagnostic steps. It should not replace direct observation or command review.

## Workflow

1. Describe the expected and actual behavior.
2. Record the environment, versions, and relevant recent changes.
3. Include exact error messages and safe diagnostic output.
4. Ask for ranked, testable hypotheses rather than a single confident cause.
5. Request read-only checks before state-changing actions.
6. Test one hypothesis at a time.
7. Record the result and update the evidence.
8. Confirm the fix and check for side effects.

## Prompting guidance

Ask the model to distinguish observations from inferences, explain why each diagnostic step is relevant, and flag commands that change or delete data. Remove credentials, tokens, private URLs, and personal information before sharing logs.
